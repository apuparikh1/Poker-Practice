# Poker Practice

A Texas Hold'em practice table built with React and Vite. Play heads-up against three bots at a felt table, with pot/bet tracking, hand evaluation, and an optional hand-strength hint.

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser.

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — build for production
- `npm run preview` — preview the production build
- `npm run lint` — lint with oxlint
